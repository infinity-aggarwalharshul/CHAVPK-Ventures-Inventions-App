# Security Policy

## Supported versions

This project is currently in active prototype and enhancement mode. Security updates are provided as needed for the current branch and documentation state.

## Reporting a vulnerability

Please do not report security issues publicly.

Instead, contact the maintainers through a private channel such as:

- support@chavpk.in

Provide:

- issue summary
- affected component
- reproduction steps
- severity assessment
- suggested mitigation if known

## Response expectations

The maintainers will:

- acknowledge the report promptly
- assess impact and scope
- coordinate remediation
- provide updates while the issue is addressed

## Recommended controls for live deployment

Before commercial launch, implement:

- HTTPS-only hosting
- secure environment variables
- role-based access control
- audit logging
- dependency scanning
- WAF or CDN protections where relevant
- regular security reviews and penetration testing

## Relevant legal alignment

Production deployments should consider:

- Indian cybersecurity expectations
- data protection and privacy obligations
- industry-specific compliance requirements
- secure incident response planning

This repository provides a solid foundation, but operational deployments require formal security review before public release.
