# Contributing

Thank you for your interest in contributing to this project.

## Scope

This repository is intended for product prototyping, innovation workflows, enterprise-facing front-end work, and future-ready digital transformation features.

## Code of conduct

Contributors should:

- be respectful, constructive, and professional
- avoid harmful or discriminatory content
- disclose scope honestly when proposing changes
- keep security issues private until reviewed

## Development workflow

1. Fork the repository or work on a feature branch.
2. Keep changes focused and documented.
3. Validate HTML, JavaScript, and static serving behavior before submitting.
4. Ensure there are no broken links or missing legal references.
5. Submit a pull request with a clear summary and testing notes.

## Local setup

```bash
cd /workspaces/CHAVPK-Ventures-Inventions-App
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## Documentation expectations

Any change affecting:

- privacy and data handling
- legal compliance
- business processes
- onboarding or user access
- payment flows
- AI features

should also update relevant documentation in this repository.

## Security disclosures

Please do not open public issues for security vulnerabilities. Use the process described in [SECURITY.md](SECURITY.md).

## Legal note

This project is a prototype and should be reviewed by qualified counsel before production deployment in regulated sectors or high-volume commercial use.
